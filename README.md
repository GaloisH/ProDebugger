# ProDebugger project site

Static project page for [ProDebugger](https://github.com/GaloisH/ProDebugger): the web workbench
with a few recorded example diagnoses. The chat page replays those runs in the browser; it makes
no model calls.

Generated by `web/export_static.py` in the ProDebugger repository; edit there and re-export
instead of changing these files. Paper, code and video links live in `web/static/js/site.js`.
